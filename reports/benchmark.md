# ReceiptLab 评测报告

在一张 RTX 4090 D 上用 240 张小票训练适配器，执行 60 次优化器更新。训练了 5,898,240 个适配器参数，PyTorch 峰值已分配显存为 8.18 GiB，训练循环用时 159 秒。

## 官方测试集

三种方案均使用 CORD v2 test 的 100 张原图。两个视觉模型采用相同的 4-bit 基础权重、提示词、图像上限和生成配置。OCR 的结果由规则直接组装为 JSON。总额准确率的分母是有总额标注的票据。

- **RapidOCR + 规则**　商品行精确 F1 7.2%，总额准确率 60.0%（57/95），合法 JSON 100.0%。批大小 1，平均摊销耗时 0.61 秒/张。
- **Qwen3-VL-4B 原版**　商品行精确 F1 4.8%，总额准确率 75.8%（72/95），合法 JSON 90.0%。批大小 4，平均摊销耗时 4.19 秒/张。
- **Qwen3-VL-4B + QLoRA**　商品行精确 F1 54.8%，总额准确率 84.2%（80/95），合法 JSON 91.0%。批大小 4，平均摊销耗时 3.18 秒/张。

## 拍照质量测试

取 test 划分前 20 张。每张分别使用原图、高斯模糊和 9° 旋转版本，三个版本共享标注。以下按原图、模糊、旋转顺序列出商品行精确 F1。

- **RapidOCR + 规则**　8.2% / 10.5% / 0.0%
- **Qwen3-VL-4B 原版**　2.3% / 0.0% / 0.0%
- **Qwen3-VL-4B + QLoRA**　46.5% / 37.2% / 37.2%

## 错误分析

错误计数来自 100 张原图。行数偏差只统计返回合法 JSON 的结果。单价与小计混淆只在两边商品名可唯一匹配且标注单价、小计不同时计数。

- **RapidOCR + 规则**　非法结构 0 张，少行 25 张，多行 29 张，单价填成小计 0 行。
- **Qwen3-VL-4B 原版**　非法结构 10 张，少行 4 张，多行 16 张，单价填成小计 0 行。
- **Qwen3-VL-4B + QLoRA**　非法结构 9 张，少行 6 张，多行 8 张，单价填成小计 0 行。

结果原始汇总和每个字段的 F1 见 [results.json](results.json)。评测范围为 CORD v2 的印尼小票。
